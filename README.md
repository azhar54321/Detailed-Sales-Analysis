# Detailed-Sales-Analysis <br><br>

**Project Description / Purpose** <br>

This interactive Power BI solution aggregates operational data to deliver real-time KPIs and live announcement feeds in a single dynamic reporting environment. It enables business leaders and key stakeholders to monitor performance metrics continuously while tracking urgent real-time alerts across multi-page views. <br><br>

**Tech Stack**<br>

Business Intelligence: Power BI Desktop / Power BI Service (PBIP format)

Custom Visuals: ScrollingTextVisual (Custom PBIVIZ ticker component)

Data Modeling: DAX (Data Analysis Expressions), Power Query (M Language)

Styling & Themes: Custom JSON Report Theme (CY26SU07 Base Theme) <br><br>

**Features / Highlights** <br>

**Business Problem**

Organizations often struggle to communicate critical operational updates and fluctuating performance metrics to leadership in real time. Static dashboards fail to highlight urgent alerts, leading to delayed decision-making and missed operational insights across teams. <br>

**Goal of the Dashboard**<br>

To create a high-impact, multi-page visual workspace that unifies key business KPIs with dynamic ticker notifications, giving decision-makers immediate visibility into operational trends and time-sensitive alerts.

**Walkthrough of Key Visuals**<br>

**Live Ticker / Announcement Bar (ScrollingTextVisual):** Prominently featured on the main dashboard to broadcast streaming alerts, high-level summaries, and critical announcements in real time.

**Primary Executive Dashboard (Page 1):** A high-density visual hub featuring 17 target KPIs, interactive slicers, trend charts, and card visuals designed for quick operational health checks.

**Detailed Breakdown View (Page 2):** A focused secondary page dedicated to granular analysis, multi-dimensional drill-downs, and deep-dive metric comparisons.<br><br>

**Business Impact & Insights**<br>

**Faster Incident Response:** Live scrolling feeds ensure critical updates are immediately visible to all viewers without navigating away from key metrics.

**Enhanced Decision-Making:** Consolidating high-level executive cards with detailed drill-down pages streamlines analysis from macro trends down to individual transactions.

**Increased Engagement:** Clean visual layouts and interactive filtering encourage cross-functional teams to explore data proactively. <br><br>
